# History of the original repository

`ai-hologram/` holds every plan, decision, prompt, note and organizational file of the original repository [`IWatchSheep/ai-hologram`](https://github.com/IWatchSheep/ai-hologram), copied **unchanged** from its final commit `1b8c143` (tag `archive-2026-10-20`), at the same paths. Each file's SHA-256 is listed in `docs/PROVENANCE.sha256` and checked by `run_checks.ps1`.

They are **historical reference**: the stage plans (`docs/stages/STAGE_00.md` to `STAGE_04.md`) hold the exact expected values that the rebuilt code must reproduce; `docs/DECISIONS.md` holds decisions D-001 to D-045, including the instrumentation exception IE-1 (D-041) and the Stage 4 measurement readings. The new repository's decision log continues from D-046.

The original C++ source code is not copied: it is rebuilt from the beginning (`docs/RULES.md`). It remains available, unchanged, at tag `archive-2026-10-20` of the original repository, and the C1 baseline it defines is frozen at tag `stage-3` (commit `7587f38`) there.
