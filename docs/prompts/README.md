# Prompts

Every instruction given to a coding assistant is saved here **before** it is used, named by stage and sub-stage (for example `stage_0a_prompt.txt`, `stage_0a_followup_1.txt`), and committed with the plan or with the work it produced (rule R24). The prompts of the original repository are in `docs/history/ai-hologram/docs/copilot_prompts/`.
